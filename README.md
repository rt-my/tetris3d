# Monolite 3D

Gioco 3D di blocchi che cadono in un pozzo: si riempiono interi piani per farli esplodere.
Grafica WebGL (three.js), musica ed effetti generati al momento, comandi da tastiera e touch.

Opzioni: modalità Classica, Zen e Lampo; quattro temi; pozzi da 4×4 a 7×7; pezzi bomba,
rallentatore, pioggia di meteore, raggi X e una demo che gioca da sola.

Si gioca aprendo `index.html` da un server web (per esempio GitHub Pages).
